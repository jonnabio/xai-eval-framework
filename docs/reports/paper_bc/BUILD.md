# Paper B+C — build guide

Target venue: ***Inteligencia Artificial*** (IBERAMIA), research article, double-blind review,
no publication fee. Submission details: `IBERAMIA_SUBMISSION.md`. Venue history:
`TMLR_REJECTION_RECORD.md` and ADR-0020.

## Files

| File | What it is |
|---|---|
| `paper_bc_iberamia.tex` / `.pdf` | Manuscript, 32 pp A4 (review build). The PDF is the file uploaded |
| `paper_bc_iberamia_appendix.tex` | Appendix A (Tables S1–S6), `\input` after the references |
| `iberamia.sty`, `logo.png` | Journal template files, unmodified (from `iberamia_LaTex.zip`) |
| `figures/` | Figures, each regenerated by a committed script |
| `paper_bc_artifacts.zip` | Artifact bundle (gitignored; built on demand) |

The abstract, the Spanish Resumen and both keyword lists are not typed in the manuscript. They
are generated from `pub/claims.toml` (`[papers.paper_bc]`: `abstract_en_tex`,
`abstract_es_tex`, `keywords_en_tex`, `keywords_es_tex`) into `pub/fragments/` by
`python scripts/pubs/generate_fragments.py`. In `claims.toml` every LaTeX backslash is doubled
(RCA-003).

## Build

From the repository root:

```bash
./tools/tectonic-portable/tectonic docs/reports/paper_bc/paper_bc_iberamia.tex
```

Windows PowerShell:

```powershell
.\tools\tectonic-portable\tectonic.exe .\docs\reports\paper_bc\paper_bc_iberamia.tex
```

Or, where `make` is installed, `make` from `docs/reports/paper_bc`. The appendix is built as
part of the manuscript; it is not compiled on its own.

## Review build and camera-ready build

One switch in the preamble:

- **Review (default):** `\camerareadyfalse`. The author block reads "Authors omitted for
  double-blind review". The repository URL and the Zenodo DOI are withheld.
- **Camera-ready:** `\camerareadytrue`. This restores the author block, the GitHub URL and
  `\zenodoversiondoi`. Also fill in the publication counters (`year`, `volume`, `issue`, `page`,
  `\thispaperdoi`) that the journal assigns.

After every review build, run the anonymity check in `IBERAMIA_SUBMISSION.md` §5.

## Engine

The journal's template assumes pdfLaTeX (`[pdftex]{color,graphicx}`). The local build is
Tectonic (XeTeX), so the manuscript loads `xcolor` and `graphicx` without a driver option. The
journal receives only the PDF, so the engine does not matter to it. `iberamia.sty` itself is
unmodified.

## Before every commit that touches the manuscript

```bash
python scripts/pubs/verify_claims.py
python scripts/pubs/verify_sync.py
python scripts/pubs/verify_exp4_reconstruction.py
python scripts/pubs/scan_shared_literals.py --strict
```

All four must pass. A number is registered in `pub/claim_registry.toml` before it is printed
(RCA-001), and the last script confirms that no result of the published RIMI paper is
re-reported. Layout numbers count too: write a column width as `12cm`, not `0.78\linewidth`,
or the scanner treats it as a result.

## Artifact bundle

```bash
python scripts/pubs/build_artifact_bundle.py   # needs data/adult.csv
```

It writes `paper_bc_artifacts.zip`, including the paper PDF with its appendix, and refuses to
write a bundle with a missing input. Build the PDF first. The journal does not take
supplementary uploads; the bundle is part of the code and data release.
