# Paper B+C — build guide

Target venue: **PeerJ Computer Science** (Research Article, single-blind review). The TMLR
submission was desk-rejected; see `TMLR_REJECTION_RECORD.md`. Submission details are in
`PEERJ_SUBMISSION.md`.

## Files

| File | What it is |
|---|---|
| `paper_bc_peerjcs.tex` / `.pdf` | Main manuscript (26 pp in the review build) |
| `paper_bc_peerjcs_supplemental_S1.tex` / `.pdf` | Supplemental Article S1: Tables S1–S6 (6 pp) |
| `wlpeerj.cls` | PeerJ LaTeX class v1.2, unmodified (copy from `rstudio/rticles`, the same class the Overleaf template ships) |
| `figures/` | Figures, each regenerated by a committed script |
| `paper_bc_artifacts.zip` | Supplemental Data S1 (gitignored; built on demand) |

The abstract and keywords are not typed in the manuscript. They are generated from
`pub/claims.toml` (`[papers.paper_bc]`) into `pub/fragments/` by
`python scripts/pubs/generate_fragments.py`, and `\input` by the manuscript. In `claims.toml`
every LaTeX backslash is doubled (RCA-003).

## Build both PDFs

From the repository root:

```bash
./tools/tectonic-portable/tectonic docs/reports/paper_bc/paper_bc_peerjcs.tex
./tools/tectonic-portable/tectonic docs/reports/paper_bc/paper_bc_peerjcs_supplemental_S1.tex
```

Windows PowerShell:

```powershell
.\tools\tectonic-portable\tectonic.exe .\docs\reports\paper_bc\paper_bc_peerjcs.tex
.\tools\tectonic-portable\tectonic.exe .\docs\reports\paper_bc\paper_bc_peerjcs_supplemental_S1.tex
```

Or, where `make` is installed, `make all` from `docs/reports/paper_bc`.

## Review build and camera-ready build

- **Review (default):** `\documentclass[fleqn,10pt,lineno]{wlpeerj}`. PeerJ requires line
  numbers for peer review.
- **Camera-ready / preprint:** remove `lineno`.

Review is single-blind, so the author block is always printed. There is no anonymous build.

## Fonts

`wlpeerj.cls` loads Type 1 Times and Helvetica, which need pdfLaTeX. The local build uses
Tectonic (XeTeX), so the manuscript maps them to the TeX Gyre Termes/Heros/Cursor clones inside
`\ifXeTeX`. Under pdfLaTeX (PeerJ's system, Overleaf) that block does nothing and the class's
own fonts load. Page breaks can differ slightly between the two.

## Before every commit that touches the manuscript

```bash
python scripts/pubs/verify_claims.py
python scripts/pubs/verify_sync.py
python scripts/pubs/verify_exp4_reconstruction.py
python scripts/pubs/scan_shared_literals.py --strict
```

All four must pass. A number is registered in `pub/claim_registry.toml` before it is printed
(RCA-001), and the last script confirms that no result of the published RIMI paper is
re-reported here.

## Separate figure and table files (PeerJ upload)

```bash
python scripts/pubs/export_peerj_upload.py
```

This writes `peerj_upload/Figure1-4.pdf` and `Table1-13.tex`, derived from the manuscript.
Re-run it after any change to a figure or table. The figures come from
`scripts/generate_paper_b_figures.py` (Figures 1-2) and `scripts/generate_exp3_gap_figure.py`
(Figure 3). Figure 4 is TikZ. PeerJ wants no titles inside figure images; titles belong in
the captions.

## Artifact bundle (Supplemental Data S1)

```bash
python scripts/pubs/build_artifact_bundle.py   # needs data/adult.csv
```

It writes `paper_bc_artifacts.zip`, which includes the Supplemental Article S1 PDF, and refuses
to write a bundle with a missing input. Build the supplement PDF first.

## Notes

- No BibTeX step: references are an embedded `thebibliography` in author–year form (natbib).
  PeerJ restyles references at production.
- `\zenodoversiondoi` holds the version DOI of the archived snapshot,
  `10.5281/zenodo.23111684` (`ZENODO_RELEASE.md`). If the code or data change before filing,
  a new Zenodo version is needed and this macro must be updated.
- `tools/tectonic-portable/` is gitignored, so a fresh worktree does not have it; copy
  `tectonic.exe` in explicitly before building there.
- The TMLR source files are at tag `tmlr-submission-12779`.
